# WonderCode Sandbox
Offline PWA for InTouch QuickScript, ArchestrA C# and Historian SQL. Built for AGAC SCADA engineers.
Run: `npm start` → http://localhost:8080. Deploy: push to `main` (GitHub Pages workflow included).
Tabs autosave to localStorage; Export/Import uses JSON. Tag converter: InTouch ↔ `Me.` attributes.
